-- Revenue by day, last 7 days
SELECT
  date_trunc('day', created_at) AS day,
  COUNT(*) AS orders,
  SUM(amount) AS revenue
FROM orders
WHERE created_at >= NOW() - INTERVAL '7 days'
GROUP BY day ORDER BY day;

🚀 Install and Start in 2 Minutes

NexQL is free and optimized for day-to-day PostgreSQL work inside VS Code.

  1. Open Extensions in VS Code (Ctrl+Shift+X).
  2. Search for ric-v.postgres-explorer.
  3. Install the extension and create your first connection.
  4. Open a .pgsql notebook and run your first query.
code --install-extension ric-v.postgres-explorer

Then open NexQL from the editor sidebar and run your first notebook cell.
